Solution

Conflux HQ turns complaints into telemetry

1. DetectOne feed X/IG/FB + calls + branch. AI reads English, Pidgin, Yoruba, Hausa, Igbo.
2. InvestigateMath flags spike (median + MAD, 15-min). Agent checks switch logs + releases.
3. DecidePlain-language cause, ranked by volume, growth, money at risk. Rules engine if cloud down.
4. ActDrafts customer message + IT ticket. Human approves money moves.
Social listening is the sensor. Value is detection + cause + handoff. Detection = math. Action = human.
